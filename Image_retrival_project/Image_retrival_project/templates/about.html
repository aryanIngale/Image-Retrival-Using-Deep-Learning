Project Name: Image Retrieval Using Deep Learning

Technique Used - Content-Based Image Retrieval (CBIR)



Content-Based Image Retrieval (CBIR) searches images by visual similarity instead of text labels. It extracts features such as color, texture, and shape from images and compares them with a database.

With deep learning models like ResNet, CBIR becomes far more accurate because neural networks extract high-dimensional feature vectors that represent the image much more effectively.
